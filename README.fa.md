# گریست دسکتاپ فارسی — نسخهٔ ۰.۴.۰

این نسخه، Grist Desktop را با لایهٔ فارسی مخزن
[`grist-core-fa`](https://github.com/AliMalakoo/grist-core-fa) ترکیب می‌کند: تقویم جلالی،
چیدمان راست‌به‌چپ، ترجمهٔ کامل رابط، و فونت وزیرمتن که داخل برنامه قرار دارد. برنامه
بدون اینترنت کار می‌کند و هیچ داده‌ای به بیرون نمی‌فرستد.

| جزء | نسخه |
| --- | --- |
| Grist Desktop | ۰.۴.۰ (بر پایهٔ ۰.۳.۱۷) |
| Grist Core | v1.7.22 |
| لایهٔ فارسی | commit `e799de0` از مخزن `grist-core-fa` |

## چه چیزی در این نسخه تازه است؟

- **زبان پیش‌فرض فارسی:** در پنجرهٔ دسکتاپ، رابط بدون هیچ تنظیمی فارسی و راست‌به‌چپ است.
  اگر در حساب کاربری یا کوکی `grist_user_locale` زبانی صریح انتخاب شده باشد، همان زبان
  اولویت دارد و رابط به انگلیسی (یا هر زبان دیگر) برمی‌گردد.
- **راست‌به‌چپ از همان اولین فریم:** زبان و جهت صفحه در سمت سرور هم ست می‌شوند، پس صفحهٔ
  اولیه به‌جای چپ‌به‌راستِ چشمک‌زن، مستقیم راست‌به‌چپ بالا می‌آید.
- **سندهای جدید با زبان `fa-IR`:** تاریخ سلول‌ها در سند تازه از ابتدا جلالی است. سندهای
  قدیمی زبان خودشان را نگه می‌دارند. با متغیر محیطی `GRIST_DEFAULT_LOCALE` می‌توانید
  پیش‌فرض را عوض کنید (مثلاً `en-US`).
- **منوی برنامه و دیالوگ‌های بومی فارسی:** پرونده، ویرایش، نمایش، پنجره و راهنما، به‌همراه
  دیالوگ‌های باز کردن، ذخیره و درون‌ریزی فایل و پیام‌های به‌روزرسانی.
- **فونت وزیرمتن آفلاین:** فونت فارسی همراه برنامه است و کدها همچنان فونت تک‌عرض خود را
  نگه می‌دارند.
- **به‌روزرسان خودکار خاموش:** نسخهٔ انگلیسیِ بالادستی به‌طور پیش‌فرض جای این نسخه را
  نمی‌گیرد. برای روشن‌کردن آن `GRIST_DESKTOP_USE_UPDATE=true` را ست کنید.
- **آماده‌سازی ایمن هسته:** `yarn run setup` لایه را فقط روی هستهٔ تمیزِ همان نسخه اعمال
  می‌کند و با `node scripts/apply-persian.js --check` می‌توانید سلامت آن را بسنجید.

## دانلود و نصب

فایل نصب ویندوز ۶۴بیتی از صفحهٔ **Actions → Build Persian installers** همین مخزن
قابل دریافت است؛ خروجی هر اجرا یک artifact به نام `grist-desktop-fa-windows-x64` است
که فایل `.exe` داخل آن قرار دارد. با push یک تگ `v*` همین فایل‌ها به‌صورت پیش‌نویس
(draft) در صفحهٔ Releases هم گذاشته می‌شوند.

> فایل نصب امضای دیجیتال ندارد و ممکن است Windows SmartScreen هشدار بدهد. این نسخه
> شناسهٔ نصب نسخهٔ اصلی (`com.getgrist.grist`) را حفظ می‌کند و ممکن است جای آن نصب شود؛
> پیش از نصب یا ارتقا از داده‌ها پشتیبان بگیرید.

برای لینوکس، artifact به نام `grist-desktop-fa-linux-x64` شامل یک فایل AppImage است.

## ساخت از منبع

پیش‌نیازها: **Node.js 22**، **Yarn 1.22**، **Python 3.11**، `git`، `bash` و ابزار
کامپایل بومی برای `sqlite3` (روی ویندوز همه را در Git Bash اجرا کنید و Git را با
پشتیبانی symlink نصب کنید).

```bash
git submodule update --init --recursive
yarn install --network-timeout 300000 --ignore-optional
yarn run setup          # لایهٔ فارسی + فونت + sandbox پایتون
yarn run build
yarn run test           # آزمون دود و آزمون‌های دسکتاپ
yarn run electron --win nsis --x64   # ساخت نصب‌کننده ویندوز
```

نصب‌کننده در `dist/` ساخته می‌شود. اگر فقط می‌خواهید برنامه را بدون بسته‌بندی اجرا کنید،
پس از `build` دستور `yarn run electron:preview` را بزنید.

### بررسی لایهٔ فارسی

```bash
node scripts/apply-persian.js --check
```

این دستور بررسی می‌کند که ۱۹ فایل هسته، فونت‌ها و قلاب‌های دسکتاپ دقیقاً همان چیزی باشند
که در `localization/grist-core-fa/` ثبت شده است. اگر هسته را دستی تغییر داده باشید،
عمداً خطا می‌دهد و چیزی را بازنویسی نمی‌کند.

## زبان، تاریخ و داده‌ها

- **زبان رابط:** پیش‌فرض فارسی است. برای انگلیسی می‌توانید در تنظیمات حساب زبان را
  عوض کنید؛ انتخاب شما بر پیش‌فرض اولویت دارد.
- **زبان سند:** تاریخ سلول‌ها به زبان سند بستگی دارد. برای جلالی باید زبان سند
  `fa-IR` باشد (سندهای تازه به‌طور پیش‌فرض همین‌اند). ستون تاریخ هم تیک «تقویم جلالی»
  دارد و می‌توانید برای هر ستون جدا تصمیم بگیرید.
- **محل داده:** سندها به‌صورت فایل‌های `.grist` در پوشهٔ Documents ذخیره می‌شوند و
  پیکربندی برنامه در پوشهٔ دادهٔ کاربر سیستم است. پیش از ارتقا از این دو پشتیبان بگیرید.

## محدودیت‌های شناخته‌شده

- داده‌ها همیشه میلادی و UTC ذخیره می‌شوند؛ جلالی فقط نمایش و ورود داده است. پس خروجی،
  فیلتر و مرتب‌سازی برای دیگر ابزارها قابل‌فهم می‌ماند.
- صفحه‌های ثابت سمت سرور (ورود، خطا، فرم اشتراک) هنوز جهت را از HTML نمی‌گیرند؛ این
  محدودیت در خود لایهٔ فارسی ثبت شده و روی پنجرهٔ اصلی برنامه اثری ندارد.
- در سندی که زبانش انگلیسی است، چسباندن (paste) رشتهٔ جلالی در ستون دارای تیک جلالی
  ممکن است میلادی خوانده شود؛ تایپ دستی در سلول تیک ستون را رعایت می‌کند.
- فایل نصب ویندوز امضا نشده است.

جزئیات فنی لایه، فهرست فایل‌ها و روش به‌روزرسانی آن در
`localization/grist-core-fa/README.md` آمده است.
